I put together a set of ReVanced patches to clean up TikTok's feed. The ad
blocker and TikTok Shop filter can be toggled separately, and there are optional
patches for download controls and installing the patched app alongside the
official one.

This is a standalone community bundle built with ReVanced Patcher (not an
official ReVanced project). Since the Shop filter relies on feed metadata,
sneaky unlabelled sponsorships can still slip through. Because patches target
specific TikTok versions, check the repo for the currently supported APK and
setup steps.
