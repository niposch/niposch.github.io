I use these patches to filter TikTok's feed. The ad and Shop filters can be enabled separately; optional patches add download controls and a separate installation.

This is an independent community project using ReVanced Patcher, with no official ReVanced affiliation. The repository records the supported TikTok version and current setup instructions. The Shop filter follows feed metadata, so it does not identify every possible promotion.
