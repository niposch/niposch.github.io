MoniTopo records active displays, their positions, the primary display, resolution, refresh rate, orientation, UI scale, and HDR state as a profile.

The project is still in active development. Windows' per-monitor scaling contract and ambiguous identical monitors need care, and synthetic tests do not replace verification on real display hardware.

The repository records current prerelease limitations and the manual hardware checklist.
